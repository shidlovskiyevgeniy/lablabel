# lablabel.ru

Сайт производства визиток LABLABEL: бумага, пластик ПВХ, фанера с гравировкой, NFC.
Чистая статика — HTML, CSS, один JS-файл. Никакой сборки, никаких зависимостей.

```
index.html            главная (все секции)
privacy.html          политика конфиденциальности (152-ФЗ)
error.html            страница 404
robots.txt sitemap.xml
assets/css/styles.css
assets/js/app.js      калькулятор, меню, отправка формы, настройки CONFIG
assets/img/favicon.svg
functions/order/      Yandex Cloud Function: заявка → Telegram
serve.js              локальный просмотр (в продакшене не нужен)
```

## Локальный просмотр

```bash
node serve.js
```

Откроется на http://localhost:4173

## Что заменить перед публикацией

Ищите по проекту метку `ЗАМЕНИТЬ`:

| Где | Что |
|---|---|
| `index.html` (шапка, форма, подвал) | телефон, Telegram, WhatsApp, e-mail |
| `privacy.html` | ИНН и e-mail оператора |
| `assets/js/app.js` → `CONFIG` | `telegram`, `whatsapp`, `orderEndpoint` |

Пока `orderEndpoint` пуст, форма не отправляет заявку, а копирует её текст в буфер и просит написать в мессенджер — сайт можно публиковать и без бэкенда.

Ещё стоит подготовить `assets/img/og.png` (1200×630) — картинку для превью ссылки в мессенджерах, и `assets/img/apple-touch-icon.png` (180×180).

## Публикация в Yandex Cloud (Object Storage + CDN)

Ориентировочная стоимость: 100–300 ₽ в месяц.

### 1. Бакет

1. Yandex Cloud → **Object Storage** → создать бакет с именем **`lablabel.ru`** (имя бакета должно совпадать с доменом).
2. Доступ на чтение объектов — **публичный**.
3. Вкладка **«Веб-сайт»** → «Хостинг»: главная страница `index.html`, страница ошибки `error.html`.
4. Загрузить файлы: `index.html`, `privacy.html`, `error.html`, `robots.txt`, `sitemap.xml`, папку `assets`.
   Папки `functions` и файла `serve.js` в бакете быть не должно.

Проверка: сайт откроется по адресу `https://lablabel.ru.website.yandexcloud.net`.

### 2. Домен и HTTPS

1. **Certificate Manager** → выпустить сертификат Let's Encrypt для `lablabel.ru` и `www.lablabel.ru`, тип проверки — DNS.
2. У регистратора домена (или в Cloud DNS, если делегируете зону) добавить TXT-запись, которую покажет Certificate Manager, и дождаться статуса **Issued**.
3. **Cloud CDN** → создать ресурс:
   - источник — бакет `lablabel.ru` (вариант «Бакет Object Storage»);
   - доменное имя ресурса — `lablabel.ru`;
   - сертификат — выпущенный на шаге 1;
   - включить редирект HTTP → HTTPS и сжатие на лету.
4. В DNS домена добавить CNAME (или ANAME для корня — зависит от регистратора) на адрес вида `cl-xxxxxxxx.edgecdn.ru`, который покажет CDN-ресурс.

### 3. Обновление сайта

```powershell
.\deploy.ps1
```

Скрипт синхронизирует файлы в бакет через AWS CLI (Object Storage S3-совместим) и сбрасывает кэш CDN. Перед первым запуском:

```powershell
aws configure --profile lablabel   # Access Key ID и Secret из сервисного аккаунта
```

Сервисному аккаунту нужна роль `storage.editor` на бакет (и `cdn.editor`, если сбрасывать кэш через `yc`).

## Заявки в Telegram (Cloud Function)

1. Создать бота у **@BotFather**, получить токен.
2. Написать боту любое сообщение, открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять оттуда `chat.id`.
3. Yandex Cloud → **Cloud Functions** → создать функцию `lablabel-order`:
   - среда выполнения **Node.js 22**;
   - загрузить содержимое папки `functions/order` (`index.js`, `package.json`);
   - точка входа — `index.handler`;
   - таймаут 10 с, память 128 МБ;
   - переменные окружения: `TG_TOKEN`, `TG_CHAT`, `ORIGIN=https://lablabel.ru`;
   - отметить **«Публичная функция»**.
4. Скопировать URL функции и вписать его в `assets/js/app.js` → `CONFIG.orderEndpoint`.
5. Перезалить сайт и проверить: заявка должна прийти в Telegram.

В функции уже есть honeypot-поле и ограничение «не чаще одной заявки с IP в 20 секунд».

## Кабинет мастера и КП

`master.html` — закрытая (noindex, без ссылок с сайта) страница расчёта заказа: себестоимость по статьям, налог НПД, чистая прибыль, режим «по прайсу сайта» или «себестоимость + наценка», минимальный чек, упаковка, доставка. Справочник (материалы, Epson, Bambu, нормы времени) хранится в localStorage браузера, переносится экспортом/импортом JSON; значения по умолчанию — `REF_DEFAULT` в `assets/js/master.js`.

Состояние расчёта сжимается в ссылку (`?s=` — для себя, со справочником). Клиенту уходит `kp.html?c=…` — только строки цены, итог, срок и заметка, без себестоимости. Прайс кабинет берёт из `PRICES` в `app.js`, отдельно его править не нужно.

**Журнал расчётов.** Каждый расчёт, отправленный клиенту (кнопки «Открыть КП», «Ссылка на КП», «Текст в мессенджер»), попадает во вкладку «Журнал»: дата, клиент, вид, тираж, сумма и прибыль. Оттуда можно открыть то же КП, повторить расчёт в форме или удалить запись; «Выгрузить CSV» даёт файл для Excel — удобно свести выручку за месяц. Хранится в localStorage (`lablabel.master.log.v1`, последние 100 записей), повторная отправка того же расчёта обновляет запись, а не плодит дубли.

Текущий расчёт автосохраняется (`lablabel.master.order.v1`) и восстанавливается при следующем открытии; кнопка «Новый расчёт» в шапке очищает форму. Если браузер не даёт доступ к буферу обмена, под кнопками появляется поле с текстом для ручного копирования.

## Страницы видов визиток (SEO)

Четыре отдельные страницы под поисковые запросы — у каждой свой title, описание, цены по тиражам, FAQ и разметка Schema.org (Product, FAQPage, BreadcrumbList):

| Файл | Запросы, под которые сделана |
|---|---|
| `nfc-vizitki.html` | NFC-визитки, визитка с чипом, электронная визитка |
| `plastikovye-vizitki.html` | пластиковые визитки, ПВХ-визитки, визитка-карта |
| `vizitki-iz-fanery.html` | деревянные визитки, визитки из фанеры, лазерная гравировка |
| `bumazhnye-vizitki.html` | бумажные визитки, печать визиток, визитки недорого |

Страницы **собираются скриптом**, править их руками не нужно:

```bash
python tools/build-pages.py
```

Тексты, цены, вопросы и контакты лежат в `tools/build-pages.py` — там же шапка и подвал, общие для всех четырёх страниц. Скрипт перезаписывает `*.html` и обновляет `sitemap.xml`. Контакты в шапке и подвале помечены `ЗАМЕНИТЬ`: правим в скрипте, пересобираем — меняется на всех страницах сразу.

С главной на них ведут ссылки «Подробнее» в карточках видов и блок «Визитки» в подвале. Обратно: кнопка «Рассчитать стоимость» ведёт на `/?kind=nfc#calc` — калькулятор на главной сразу открывается с нужным видом.

## Прайс

Цены и пороги скидок лежат в `assets/js/app.js` → `PRICES`, доплаты — в константах `DESIGN_FEE`, `TWOSIDE_K`, `URGENT_K`. Это же нужно поправить в карточках товаров в `index.html`, если меняете базовые «от».

| Вид | Цена за штуку по тиражам |
|---|---|
| Бумажные | до 250 — 12 ₽ · до 500 — 10 ₽ · до 1000 — 8,5 ₽ · от 1000 — 7 ₽ |
| Пластик ПВХ | до 50 — 200 ₽ · до 100 — 180 ₽ · от 100 — 160 ₽ |
| Фанера | до 50 — 240 ₽ · до 100 — 220 ₽ · от 100 — 200 ₽ |
| NFC | до 10 — 650 ₽ · до 50 — 600 ₽ · от 50 — 550 ₽ |

Базовые цены и себестоимость взяты из бизнес-плана проекта; скидки за объём подобраны так, чтобы прибыль с единицы оставалась положительной на всех ступенях.
